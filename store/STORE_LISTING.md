## Name

Promp it — Visual Prompt Analyzer

## Short description

One-click vision analysis for any image: get a complete AI prompt with subject, pose, camera, lighting, composition, and style.

## Full description

Promp it lets you describe any image in one click and receive a complete, production-ready AI image-generation prompt. Select a web image, right-click it, or capture a specific section; your chosen vision model studies the visible evidence and turns it into clear generation language. Developed by https://baydy.art

Promp it identifies visible subject details, pose, camera angle, perspective, composition, lighting, color, materials, style, mood, and relevant text. It then builds a detailed English generation prompt and structured JSON, tailored to the image model or platform you use.

Key features:

- Analyze full web images or a selected section.
- Choose what to describe: subject, pose, camera, angle, composition, lighting, style, or background.
- Tailor output for Generic, Flux, Qwen Image, ChatGPT Images, or Nano Banana.
- Keep visible text out of the prompt, add a negative prompt, refine the result, or roll an image-compatible modern art direction.
- Store prompts and source images locally, then export history as a ZIP.
- Use local Ollama by default. An OpenAI-compatible vision endpoint is available only when you configure and choose it.

## Privacy summary for the listing

Promp it does not run analytics, advertising, tracking, or remote code. It stores its settings and prompt history in the browser profile. For analysis, the selected image pixels are sent to the local Ollama server you configure. If you explicitly select an external OpenAI-compatible vision endpoint or enable automatic fallback, the selected image pixels are sent to that endpoint instead. See the hosted privacy policy before submitting.
