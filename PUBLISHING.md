# Publishing Promp it on GitHub

## Included archives

- `Promp-it-v1.10.13-source.zip` contains the full source, documentation, previews, and tests for a GitHub release.
- `Promp-it-v1.10.13-extension.zip` contains only the unpacked Manifest V3 extension files needed for installation or store submission.
- `release/stores/` is generated by `node scripts/build-store-packages.js` and contains separate Chrome, Edge, Firefox, and Safari upload packages.

## Before publishing

1. Run `node tests/smoke.test.js` from the project folder.
2. Create a new GitHub repository and upload the project source. Do not commit the `release/` folder; it is intentionally ignored.
3. Create a GitHub Release tagged `v1.10.13` and attach the two ZIP files from `release/`.
4. License: Promp it is published under the open-source MIT License (Developed by https://baydy.art).

For browser-store submission, use [store/STORE_SUBMISSION.md](store/STORE_SUBMISSION.md) and the packages in `release/stores/` instead of the general GitHub-release ZIPs.

## Local installation

Unzip `Promp-it-v1.10.13-extension.zip`, open `brave://extensions` or `chrome://extensions`, enable Developer mode, and choose **Load unpacked** on the extracted folder.
